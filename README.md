# 🧮 少儿数学速算 · 语音答题

给小朋友练「十以内加减法」的小网页：看题 → **随口报答案**（边说边识别）→ 出现绿色 ✔ 后**点「下一题」**，做完 80 题统一公布**用时**和**正确率**。

## 功能

- ✅ 十以内加减法混合共 **80 题**（加法保证两数之和 ≤ 10，减法保证结果不为负）
- ✅ **语音答题（持续监听模式）**：识别器全程在线，说话过程中实时解析数字（`interimResults`），说完立刻记录；同音字自动纠错（幺/俩/久/酒/时/拾…）
- ✅ **收录后 0.5 秒锁定**：答案收录后短时间内可覆盖，之后锁定本题不再接收语音，防止误覆盖
- ✅ **防尾音串题**：点「下一题」时重启识别器清空音频缓冲 + 1.2 秒语音保护期，上一题的尾音不会误录到新题
- ✅ **「下一题」大按钮切题**（也支持电脑键盘 → 键或回车）
- ✅ **最后统一判分**：答题过程中不显示对错（保持节奏），做完统计用时、答对题数、正确率、未作答数、星级、逐题回顾（绿=对 · 红=错 · 灰=未答）
- ✅ **最好成绩本地保存**：首页展示历史最佳
- ✅ **数字键盘备用**：麦克风不可用时可打开，键盘打开时题目卡片自动压缩，小屏也能完整显示

## 怎么运行

整个项目只有一个 `index.html` 文件，无需安装任何东西。

**方式一（最简单）**：直接双击 `index.html` 用 Chrome / Edge 打开。

**方式二（推荐，语音识别更稳定）**：在项目文件夹里启动一个本地服务器：

```bash
# 任选其一
python -m http.server 8000
npx serve .
```

然后浏览器访问 `http://localhost:8000`。

## 使用说明

1. 点击「🎤 开始答题」，浏览器会请求麦克风权限，请点「允许」
2. 屏幕出现算式（如 `7 + 3 = ?`），随口说出答案，页面立刻显示绿色 ✔
3. 点「下一题 ➡」按钮进入下一题（电脑上也可按 → 键）
4. 80 题全部完成后，统一显示用时、正确率、未作答数和逐题回顾

## 与安卓 App 版的关系

本仓库是网页版（语音走浏览器 Web Speech API，安卓手机 + 大陆网络下不可用）。
同项目另有一个 **安卓 APK 版**（内置 Vosk 离线中文识别引擎 + 语法约束，
不依赖 Google 服务，vivo/小米/华为等国产手机均可用），
两者交互完全一致：语音报答案 → 绿✔ → 点「下一题」→ 成绩单。

## 技术说明（给学习者的笔记）

| 技术 | 用在哪里 |
| --- | --- |
| HTML + CSS | 页面结构与样式（单文件，无依赖） |
| JavaScript | 出题逻辑（随机生成、洗牌）、计时、判分 |
| Web Speech API（`webkitSpeechRecognition`） | 中文语音识别 |
| Touch 事件（`touchstart` / `touchend`） | 滑动手势切题 |

> ⚠️ 语音识别需要 **Chrome / Edge** 等浏览器，且需要麦克风权限。
> 如果是部署到网上（GitHub Pages 等），语音功能在 HTTPS 下才能正常工作。
