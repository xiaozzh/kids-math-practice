# 🧮 少儿数学速算 · 语音答题

给小朋友练「十以内加减法」的小网页：看题 → **说出答案** → **滑动屏幕**进入下一题，做完 80 题自动统计**用时**和**正确率**。

## 功能

- ✅ 十以内加减法混合共 **80 题**（加法保证两数之和 ≤ 10，减法保证结果不为负）
- ✅ **语音答题**：使用浏览器 Web Speech API 识别中文口述答案（"8"、"八" 都能听懂）
- ✅ **滑动切题**：答完当前题后，手指左右滑动进入下一题
- ✅ **成绩统计**：总用时、答对题数、正确率、星级评价、逐题回顾
- ✅ **备用输入**：麦克风不可用时，可打开「数字答题」键盘，电脑上也可直接敲键盘

## 怎么运行

整个项目只有一个 `index.html` 文件，无需安装任何东西。

**方式一（最简单）**：直接双击 `index.html` 用 Chrome / Edge 打开。

**方式二（推荐，语音识别更稳定）**：在项目文件夹里启动一个本地服务器：

```bash
# 任选其一
python -m http.server 8000
npx serve .
```

然后浏览器访问 `http://localhost:8000`。

## 使用说明

1. 点击「🎤 开始答题」，浏览器会请求麦克风权限，请点「允许」
2. 屏幕出现算式（如 `7 + 3 = ?`），大声说出答案
3. 页面会立即显示对错和正确答案，然后左右滑动屏幕进入下一题
4. 80 题全部完成后，显示用时、正确率和星级

## 技术说明（给学习者的笔记）

| 技术 | 用在哪里 |
| --- | --- |
| HTML + CSS | 页面结构与样式（单文件，无依赖） |
| JavaScript | 出题逻辑（随机生成、洗牌）、计时、判分 |
| Web Speech API（`webkitSpeechRecognition`） | 中文语音识别 |
| Touch 事件（`touchstart` / `touchend`） | 滑动手势切题 |

> ⚠️ 语音识别需要 **Chrome / Edge** 等浏览器，且需要麦克风权限。
> 如果是部署到网上（GitHub Pages 等），语音功能在 HTTPS 下才能正常工作。
